## 3. 命令行用法（推荐日常）

### 3.1 查看已注册协议

```powershell
python -m evcpa protocols
```

### 3.2 分析十六进制报文

支持带空格、连续字符串、`0x` 前缀：

```powershell
python -m evcpa analyze --hex "68 0E 01 00 00 01 32 01 02 00 00 00 01 00 02 10 83 10"
```

### 3.3 从文件分析（最方便）

- `.hex` / 纯文本十六进制 → 按二进制帧解析  
- `.json` / 以 `{` 开头 → 按 JSON 解析  

```powershell
python -m evcpa analyze --file samples\ykc_login.hex
python -m evcpa analyze -f samples\huawei_event.json
python -m evcpa analyze -f samples\xingxing_status.json
python -m evcpa analyze -f samples\shenghong_status.json
python -m evcpa analyze -f samples\infypower_module.json
```

### 3.4 分析 JSON 字符串

```powershell
python -m evcpa analyze --json "{\"cmd\":\"notify_connector_status\",\"deviceId\":\"3201020001\",\"OperatorID\":\"MA1Y7X7X9\"}"
```

### 3.5 强制指定协议

自动识别不准时使用：

```powershell
python -m evcpa analyze --protocol ykc --file samples\ykc_heartbeat.hex
python -m evcpa analyze -p huawei -f samples\huawei_event.json
```

### 3.6 以 JSON 输出结果（便于对接脚本）

```powershell
python -m evcpa analyze --file samples\ykc_login.hex --as-json
```

## 4. 如何读懂分析结果

界面大致包含：

| 项 | 含义 |
|----|------|
| 协议 | 判定出的厂商协议及 ID |
| 置信度 | 0%~100%，越高越可信 |
| 结论 | 一句话摘要（帧类型、关键标识等） |
| 帧类型 | 如云快充 `0x01` 登录认证 |
| 方向 | `pile->platform` / `platform->pile` |
| 关键字段 | 桩号、枪号、电压电流、状态等 |
| 告警/问题 | CRC 失败、长度不符、故障码等 |
| 协议候选得分 | 各解析器打分，便于人工复核 |

**云快充特别提示**：会校验 CRC16-Modbus；CRC 不一致会标为错误。

## 5. HTTP API 用法

### 5.1 启动服务

```powershell
python -m evcpa serve --host 127.0.0.1 --port 8080
```

浏览器打开交互文档：<http://127.0.0.1:8080/docs>

局域网访问可改为：

```powershell
python -m evcpa serve --host 0.0.0.0 --port 8080
```

### 5.2 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查 |
| GET | `/protocols` | 协议列表 |
| POST | `/analyze` | 分析报文 |

### 5.3 调用示例

分析十六进制：

```powershell
curl -X POST http://127.0.0.1:8080/analyze -H "Content-Type: application/json" -d "{\"hex\":\"68 0E 01 00 00 01 32 01 02 00 00 00 01 00 02 10 83 10\"}"
```

分析 JSON，并指定协议：

```powershell
curl -X POST http://127.0.0.1:8080/analyze -H "Content-Type: application/json" -d "{\"protocol\":\"huawei\",\"json\":{\"productId\":\"FusionCharge_DC\",\"deviceId\":\"HW-CHG-00088\",\"eventType\":\"chargerStatusChanged\"}}"
```

请求体字段：

```json
{
  "hex": "可选，十六进制字符串",
  "json": "可选，对象或 JSON 字符串",
  "protocol": "可选，ykc|xingxing|shenghong|huawei|infypower"
}
```

## 6. Python 代码调用

```python
from evcpa.agent import ProtocolAgent

agent = ProtocolAgent()

# 十六进制
r1 = agent.analyze_hex("68 0E 01 00 00 01 32 01 02 00 00 00 01 00 02 10 83 10")
print(agent.explain(r1))

# JSON
r2 = agent.analyze_json({"deviceId": "3201020001", "OperatorID": "MA1Y7X7X9", "cmd": "status"})
print(r2.protocol, r2.confidence, r2.summary)

# 强制协议
r3 = agent.analyze(hex_text="68 ...", protocol="ykc")

# 结构化字典（可写日志/入库）
print(r1.to_pretty_dict())
```

## 8. 推荐工作流

1. 从抓包工具导出一条报文（Hex 或 JSON）  
2. 保存为 `my_frame.hex` / `my_msg.json`  
3. 执行：`python -m evcpa analyze -f my_frame.hex`  
4. 看置信度与候选得分；不准则加 `-p ykc` 等强制协议  
5. 关注 `warnings`（CRC、长度、故障码）  
6. 需要批量/系统对接时，用 `serve` + `/analyze`

## 9. 常见问题

**Q: 控制台中文乱码？**  
A: Windows 终端编码问题，可先执行 `chcp 65001`，或加 `--as-json` 看结构化结果。

**Q: 提示未能识别协议？**  
A: 检查报文是否完整；用 `-p` 指定协议；确认 Hex 长度为偶数。

**Q: 云快充 CRC 失败？**  
A: 多为截断、粘包未拆帧，或校验范围选错；请保证整帧从 `68` 到 CRC 完整。

**Q: 星星/盛宏/华为/英飞源字段不全？**  
A: 私有协议版本多，当前为启发式解析；可在 `evcpa/protocols/` 对应文件按厂商文档扩展字段。

**Q: 命令找不到 `evcpa`？**  
A: 先 `.\.venv\Scripts\activate`，或统一用 `python -m evcpa ...`。
