## 一、项目是什么

本地 / Web 工具，用于解析充电桩协议报文与平台业务日志，输出中文订单分析报告（启动方式、启停原因、电量费用、枪口状态、异常提示等）。

- CLI：`python -m evcpa …`
- Web：`python -m evcpa serve`（当前默认端口 **6894**）
- 可视化页：http://0.0.0.0:6894/

## 四、按业务主题汇总（你让改过什么）

### A. 协议与解析
- 云快充（YKC）→ 平台 V1.7；字段中文+英文+单位
- 微鲸协议接入
- 万马协议接入（含粘包、标签、VIN 启动、精度等）
- 平台业务日志 JSON + 设备帧互证
- 大日志多帧整单聚合，而非只解一帧

### B. Web / 使用方式
- 可视化分析页（结论式报告 + 字段表）
- serviceId / tradeNo 筛选（后合并为一个输入框）
- 多订单先列清单再选
- 去掉页脚「接口文档」入口等界面调整
- 默认端口改为 **6894**
- 推送到你的 GitHub 仓库；本机可 serve 给他人用

### C. 启停与枪口逻辑
- 远程启动 / 远程停止（remoteCmd 17/18）识别
- 无 stopReasonMsg → **用户远程停止**
- 平台守护文案（功率不为零、电量为 0）→ **平台异常停止**，直接输出中文原因
- 无远程停止 → 设备/拔枪/故障类推断
- TROUBLE：无告警疑似急停；有告警为枪口故障
- 多枪管道状态解析
- 拔枪后枪事件与本单脱钩
- 多订单发现：修正空 ID 误合并，确保可弹出选择
- 启动成功：过程数据充分即可
- 启动失败中文短语识别，启动失败 **无需复核**

### D. 电量 / 费用 / 校验
- 总电量、分时（尖峰平谷）、费用、占位费
- 过程电量 vs 账单一致性
- 分时冻结 / 过程序列合理性
- 功率×时间 ≈ 电量（含容差说明）
- 需求电压/电流字段
- 双表码为 0 时跳过误报
- 金额精度（如分→元）、电量 kWh 展示
- 充电时长改为 **仅累计 CHARGING**（已提交）

### E. 告警与异常展示
- 告警信息摘录（中文 / 告警 JSON）
- 结论里提示到设备侧核对
- 减少「疑异常」类噪音表述

## 五、功率×时间公式（你问过）

```
expected_kWh = avg_power_kW × (duration_sec / 3600)
tol = max(1.5, expected_kWh × 0.25)
通过条件：|actual_kWh − expected_kWh| ≤ tol
```

时长应使用实际充电秒数（现已优先 CHARGING 累计）。
